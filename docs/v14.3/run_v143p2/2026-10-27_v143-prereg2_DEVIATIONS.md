# 14.3 pre-registration 2 (revision 5, md5 b7562e8b): deviations and implementation readings

Run 27 October 2026 on Cardinal in `~/v143p2/`. Result: `2026-10-27_v143_T-form-reestimation_RESULT.md`. Each item names what the plan says, what was done, and why. Items 1 to 3 change what the plan would otherwise have computed; the rest are readings of points the plan leaves open, fixed in the script headers before the step they govern ran.

## Deviations

1. **CSI fallback for the sealed set's site input (Aaron's decision, 27 October 2026).** The plan builds the sealed New Hampshire and Vermont set with PREREG1 rule 7's definitions, which use the Acadian ESI v8 raster. That raster ends at 71.5 W (extent checked: xmin -71.5), so Vermont and western New Hampshire plots have no ESI. On Aaron's instruction, a stand with no ESI above 2 at v1, v2 or v0 takes the climate site index instead: `~/SiteIndex/ClimateNA_SI_m.tif`, the raster the fvs-modern calibration extracts as ClimateSI at FIA plot locations (`R/extract_raster_values.py`), entered directly in metres in the AcadianGY site slot, as `cardinal_acadgy_csisensitivity_v25.R` entered it for FIA plots (ClimateSI_ft x 0.3048, the ft to m round trip). The other conversion found in the project, CSI = 3.372 + 0.752 ESI (`htpred_csi_vs_esi.R`), relates the legacy Maine CFI climatesi to a different ESI surface and was not used. The plan's own "open" condition on ESI coverage below 80% is unchanged and still applies.
2. **PEF excluded from the fit by the registered 80% link rule, under a reading fixed before the count.** The plan does not say which records "link to a pre-visit record". The fit frame script fixed, before computing any link count, the literal reading: end-visit live records of pef_c intervals with start-visit tst 1 to 17 whose GYDB tag is live at the interval's start visit. That share is the registered decision; the forward share and the share at 12.7 cm or more are reported only.
3. **Dry runs used the real inputs for the step 2 scripts.** The plan names a dry run on synthetic stands. The frame, decomposition and sealed build scripts were dry run on the real frozen inputs into `~/v143p2/dry/` (their outputs are deterministic and are not candidate predictions); the fitter was dry run on a 5 installation subset with 40 draws so that no full-data selection was seen before the step 2 md5; engine arms were dry run on a subset of chunks.

## Implementation readings

4. **Annual step increment.** The plan integrates "the engine's annual steps" open loop with Dq, competition and site held at interval start. The base increment of each record is the A0 engine's own first annual step increment of that tree (G1, from the frozen PREREG1 A0 tree dumps `c*_pred_yr1_tree.csv` minus `c*_t1_split_tree.csv`, hardwood sub-records mapped back with the hw_formrisk_split rule and averaged with start-of-step expansion factors). G1 is held over the interval; tst and the tree's own diameter advance by annual steps through m_T and r = d / Dq. The engine's base growth is not re-evaluated at the advanced diameter.
5. **Relative size in the fit frame.** r = d / Dq with Dq computed exactly as 14.1 computes it at step 1 (all split records with expf > 0 and dbh > 0). Gate H3 checks it against the engine.
6. **CV SE.** The plan asks for the SE "across folds". With folds of unequal weight, CV is the pooled expansion weighted MSE (sum of W_f MSE_f over sum of W_f) and its SE is that of a cluster weighted mean, sqrt(K / (K - 1) * sum (W_f / W)^2 (MSE_f - CV)^2); paired differences use the same formula on fold differences.
7. **Bound check.** A draw is "at a registered bound" when the parameter is within 1e-5 of the bound.
8. **Decomposition fates.** A v1 tree whose v2 record has a status other than live, dead or cut, or that has no v2 record, is counted in R (removed), with absent and other kept apart. The scorer weights observed survivors at v2, so the weight change term W is reported and the identity is gap = S + M + I + R - W.
9. **mefia_l_c check.** The frame's tree numbers are not FIA tree identities, so survivors were linked through FIADB: the chain visit CNs at Y1 and Y2, the frame's t1 list checked against the v1 live list, and PREV_TRE_CN walked through intermediate visits (the "chained linkage"). The check counts as holding when both visits and the t1 list are recovered for 95% of stands and at least half the t1 trees link to a v2 survivor.
10. **Sealed set height column** is ACTUALHT, the Maine builder's validated choice; the plan's replacement check against an unmanaged NH and VT set reports height availability and ESI coverage on that set.
11. **TR stands** for gate H4 are 4 CTRN fit stands with an interval of 3 yr or more (traced over several annual steps); the first selection of 4 stands with 1 yr intervals could not show tst advancing, and was replaced in the dry run before any real trace.
12. **Software environment.** terra in the R 4.5.2 library needs the gdalz conda libraries (LD_LIBRARY_PATH and LD_PRELOAD of its libstdc++), set only for the sealed build.
13. **Bridge outage.** The laptop bridge that carries the Cardinal tools was down from about 06:34 to 17:46 EDT. No job was affected: the fit and selection job (15915039) ran 06:28 to 06:35 and completed, the harness and grid arrays completed, and nothing was resubmitted. Work resumed from the selection record (md5 14e49e5b, logged 06:35:12).
14. **Step 4 task map and scorer revisions.** The first step 4 task map omitted the SELN1 (leave one installation out) arm because of an awk error, and the first `v143p2_score4.R` run stopped before writing any output. SELN1 was run, and score4 was revised (N0 now skips the sealed set directory, which the plan excludes from step 4) with its md5 re-recorded before the run that counts. An earlier score4 error (the step 2 file stores r1 apart) was found and fixed in the dry test with SEL set to C0f.
